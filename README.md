# TreeStore и таблица AG Grid

Тестовое задание MStroy Frontend. В репозитории есть класс `TreeStore` на TypeScript и одноэкранное приложение на Vue 3. Класс хранит плоский массив элементов как дерево и отдаёт детей, потомков и путь к корню. Приложение загружает данные из JSON и показывает их в таблице AG Grid Enterprise.

## Требования

Нужен Node.js 24. Версия в `.nvmrc` равна `24`. Зависимости ставятся из `package-lock.json`.

## Установка и запуск

Установить зависимости:

```bash
npm install
```

Запустить приложение в режиме разработки:

```bash
npm run dev
```

Собрать production-сборку:

```bash
npm run build
```

Просмотреть собранное приложение:

```bash
npm run preview
```

Запустить тесты:

```bash
npm test
```

Проверить форматирование:

```bash
npm run format:check
```

## Как устроен проект

Класс лежит в `src/store/TreeStore.ts`. Конструктор принимает массив элементов. У каждого элемента есть `id` типа `string | number`, `parent` типа `string | number | null` и произвольные поля. Число `1` и строка `'1'` считаются разными ключами.

Внутри класса две карты. `Map` по `id` хранит сами элементы в порядке загрузки. `Map` по `parent` хранит `Set` id детей.

Публичные методы:

| Метод                | Поведение                                             |
| -------------------- | ----------------------------------------------------- |
| `getAll()`           | Возвращает все элементы в порядке загрузки.           |
| `getItem(id)`        | Возвращает элемент по id.                             |
| `getChildren(id)`    | Возвращает прямых детей или пустой массив.            |
| `getAllChildren(id)` | Возвращает всех потомков без самого элемента.         |
| `getAllParents(id)`  | Возвращает цепочку от элемента до корня включительно. |
| `setItems(items)`    | Полностью заменяет данные.                            |
| `addItem(item)`      | Добавляет элемент.                                    |
| `removeItem(id)`     | Удаляет элемент и всех потомков.                      |
| `updateItem(item)`   | Заменяет элемент. При смене `parent` переносит его к другому родителю. |

Приложение создаёт хранилище как `new TreeStore([])`. Файл данных лежит в `public/items.json`. После монтирования экрана приложение ждёт 2 секунды, запрашивает `/items.json` и передаёт массив в `setItems`. Пока ответ не получен, на экране спиннер.

Таблица лежит в `src/components/TreeTable.vue`. Включены `treeData` и `treeDataDisplayType: 'custom'`. Путь строки для AG Grid собирается из `getAllParents` в обратном порядке. Колонки:

- «№ п/п» показывает номер видимой строки, начиная с 1.
- «Категория» показывает «Группа», если у элемента есть дети, иначе «Элемент». У группы есть шеврон.
- «Наименование» берёт значение поля `label`.

## Тесты

Тесты запускаются командой `npm test`.

Тесты `TreeStore` находятся в каталоге `tests/store`. Они проверяют публичные методы класса, сохранение порядка загрузки, работу с числовыми и строковыми `id` и удаление элемента вместе с потомками.

Тесты производительности вызывают те же методы на массиве из 100 000 элементов, переносят 10 000 детей у узла, у которого таких детей 100 000, и обходят дерево глубиной 25 000 уровней.

Тесты компонентов находятся в каталоге `tests/components`. Они проверяют индикатор загрузки, запрос `/items.json` после паузы в 2 секунды, три колонки таблицы и сборку пути от корня к строке для AG Grid.
